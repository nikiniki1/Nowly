# Nowly

Your time is already telling a story. Nowly helps you see it.

Log what you are doing in a tap, return to the day later, and notice the patterns that are usually easy to miss: how much time work really takes, whether rest is actually rest, and where your attention goes.

## Features

- Choose or switch an activity in one tap
- Add details when they matter: `Work → Meeting`
- Keep your go-to activities in Favorites
- Look through and edit your activity history
- Build a set of activities that fits your own life
- See what is active right from the Home Screen
- Use Nowly in light, dark, or system appearance

## What's next

We plan to add a personal insights agent that can look at your activity data and help you spot useful patterns, ask better questions about your time, and make sense of your routine. The goal is insight, not judgment.

## Run locally

1. Clone the repository.
2. Open `Nowly.xcodeproj` in Xcode.
3. Choose the `Nowly` scheme.
4. Select an iPhone Simulator or a connected iPhone.
5. Press **Run** (`⌘R`).

The project is built with SwiftUI and requires a recent version of Xcode with an iOS Simulator installed.
